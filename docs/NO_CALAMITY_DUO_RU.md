# Terraria DUO — без Calamity Mod и без музыкальных модов

Три профиля для Steam/tModLoader Stable 1.4.4. 40 / 52 / 39 модов.

**Рекомендованный — 40:** Thorium + самостоятельный Calamity Fables + Consolaria + новые структуры, питомцы, удобный общий склад, карты и QoL.
**Epic — 52:** добавлены The Stars Above, Subworld Library, Vitality, алхимия и другие ускорители. Требует больше ОЗУ и отдельного теста переходов между измерениями.
**Thorium-only — 39:** без Fables, фокус на Thorium и дополнительных комфортных модах.

## Для 2 игроков

- Один и тот же профиль у обоих, одинаковые версии, сначала скачать все зависимости.
- Large / Expert / Classic characters. Bard+Ranger, Healer+Warrior или Bard+Mage — хорошие варианты.
- Мод The Stars Above официально предусматривает Multiplayer Compatibility Mode в серверных настройках, если переходы между измерениями дают ошибки.
- В Shared World Map настройте ручную или редкую синхронизацию; полная передача большой карты заметна по трафику.
- Перед заменой профиля сделайте резервные копии Worlds и Players.
- Не добавляйте Spirit Reforged: он требует отдельного Spirit Music Mod. Starlight River и Mod of Redemption не добавлялись в обязательный профиль из-за сообщений о проблемах кооператива.
- **Мир и сетевая игра не тестировались.** Подготовлены списки ID, конфигурации и установщик.

## Установка

1. Скачайте код репозитория (Code → Download ZIP) или готовый ZIP из чата.
2. Запустите INSTALL_NO_CALAMITY.cmd в распакованной папке.
3. Для 52 модов используйте INSTALL_NO_CALAMITY.cmd -Profile epic. Для Thorium без Fables — -Profile thorium.
4. SteamCMD пытается скачать моды официальным способом без пароля. Если загрузка ограничена, установщик показывает отсутствующие ID; завершите через tModLoader → Workshop → Mod Packs → Download All.
5. Другой игрок должен скачать **точно такой же профиль**.

Никакие .tmod не размещены в публичном репозитории: условия распространения зависят от авторов каждого мода, подписка в Workshop не даёт общего разрешения на перезалив бинарных файлов.

Официальные страницы: [Thorium](https://steamcommunity.com/sharedfiles/filedetails/?id=2909886416), [Fables](https://steamcommunity.com/sharedfiles/filedetails/?id=3449156562), [The Stars Above](https://steamcommunity.com/sharedfiles/filedetails/?id=2563862309).
