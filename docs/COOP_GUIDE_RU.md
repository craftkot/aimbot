# Calamity × Fables: конфигурация кооператива

## Новая игра
- **Оба**: актуальная **одинаковая Stable** сборка tModLoader и один выбранный профиль.
- **Мир**: Large, Expert. Персонажи: Classic. Сначала включить выбранный контент, потом сгенерировать мир.
- Если первый старт тормозит, не отключать контентные моды на уже созданном мире; проверять новую конфигурацию в копии.
- Calamity Revengeance: начать с Expert, включить только когда оба готовы. Death/Master/Infernum не включать для первого прохождения.

## Настройка модов
- Calamity Fables: конфигурация совместимости с Calamity включает опцию \`ReplaceCalamity\`, влияющую на замену дублируемого контента. Устанавливать её в UI после изучения её описания; не подменять непроверенным JSON.
- Magic Storage: один общий склад для пары. Не переставлять сердцевину и компоненты склада во время активной сетевой игры.
- Shared World Map: синхронизацию карты настроить обоим. При сетевых лагах сократить частоту/выключить мод на копии.
- BAM: не добывать цепочками структуры, декоративные блоки, блоки складов.
- Fargo's Mutant и AlchemistNPC Lite: упрощают фарм и экономику. \`max\` может заметно ускорить прогрессию.
- No More Tombs в профиле \`max\`: не отключать сообщения о смерти через его настройки из-за сообщений о проблемах.
- Catalyst / Hunt of the Old God доступны только в \`max\`, с дополнительной нагрузкой и риском конфликтов.

## Безопасность сохранений
- Перед сменой профиля сохранить **всю** папку \`tModLoader\Worlds\` (файлы \`.wld\` и \`.twld\`).
- Для персонажей сохранить \`tModLoader\Players\` (включая модовые данные).
- Не обновлять моды в середине сетевой сессии.
- У обоих игроков проверить совпадение версий контентных модов, если возникает ошибка multiplayer.

## Сервер
- Проще всего: Multiplayer → Host & Play → Invite via Steam.
- Для выделенного сервера: образец в \`server/serverconfig.example.txt\`; у него должны быть **те же** контентные моды.
- Не публиковать пароль сервера в репозитории. Использовать собственный пароль в локальном файле.
- 7777 — стандартный порт; настройка NAT/firewall понадобится только при игре по IP, не при нормальном Steam Invite.

## Тест перед полноценным прохождением
1. Оба загружаются в **новый** мир, без ошибок загрузки модов.
2. Проверяют генерацию ключевых биомов и структур Fables/Calamity.
3. 10 минут играют вдвоём с Magic Storage и общими боссами.
4. Выходят, перезаходят и проверяют сохранение персонажей/миров.
5. Только после этого начинают основной мир.
